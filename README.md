# Hotel Antik Soreang

Website hotel modern berbasis **Laravel 12 + Tailwind CSS + Vite**.

## Setup
```bash
cd HotelAntikSoreang
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

## Pages
- `/` (Welcome)
- `/home`
- `/rooms`
- `/facilities`
- `/contact`

## Fitur singkat
- UI modern (gradient + hover)
- Halaman kamar: pricing & fasilitas
- Halaman fasilitas
- Form kontak (kirim email)
